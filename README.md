# 📝 Note Keeper

Kullanıcıların hızlıca not ekleyip düzenleyebildiği, verilerini localStorage üzerinde saklayan basit ve modern bir not tutma uygulaması. Tarayıcı kapatılsa bile notlar kaybolmaz, hepsi localStorage'da güvende kalır.

## ✨ Özellikler

- 🗒️ Yeni notlar ekleme, düzenleme ve silme  
- 💾 Notları **localStorage** üzerinde kalıcı olarak saklama  
- 🎨 Modern, renkli ve sade kullanıcı arayüzü  
- ⚡ Hızlı ve responsive yapı  
- 🕓 Otomatik tarih ekleme  


## 🛠️ Kullanılan Teknolojiler

- **HTML5** 
- **CSS3** 
- **JavaScript (Vanilla JS)**
